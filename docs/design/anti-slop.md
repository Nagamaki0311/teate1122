# teate1122 AI-slop監査 基準文書

- 対象: 手作りキャンドルのブランドサイト teate1122（日本語、30代後半〜50代の女性向け、癒し・リラックス・淡いトーン・ミニマル・モダン、縦組みのヒーロー、生成り＋苔色＋灯りの橙、夜のヒーローとフッター）

- 表記ルール: 出典がない記述には【推測】と付けた。出典の内容を日本語に要約した箇所は、原文の意味から外れないようにした。

## 1. 避ける表現（25件）

各項目は「特徴（見て分かる形）」「なぜ既定の形か」「teate1122で見る点」の順に書く。

### 1-A. 色・質感

**A1. 紫〜青（またはシアン、ピンク）のグラデーション、白地に紫のグラデーション**
- 出典: S1、S3、S5（取得日 2026-10-01）
- 特徴: 青→紫、青→シアン、紫→ピンクのグラデーションを主な色として使う。ページ全体に色付きの光が広がる。ヒーローの背後に、ぼかした丸い光の玉がある。
- なぜ既定の形か: S1 によると、指示なしでランディングページを作らせると、ほぼ必ず Inter、白地に紫のグラデーション、控えめなアニメーションに寄る。原因は学習データの中心にある「安全な」選択に集まる性質（distributional convergence）だという。S3 は、学習データで最も多い色の扱いで、ブランドがないことの合図になるとしている。
- teate1122で見る点: 灯りの橙を背景のグラデーションや光の玉にして「暖かさ」を出していないか。これは同じ型を暖色にしただけである。

**A2. グラデーションの文字**
- 出典: S6（取得日 2026-10-01）
- 特徴: 見出しや強調語に、background-clip などでグラデーションを入れる。
- なぜ既定の形か: S6 は既定の表面処理の一つに挙げ、強調は太さか大きさで行うとしている。
- teate1122で見る点: 「灯り」を表すために、見出しを橙→生成りのグラデーション文字にしていないか。

**A3. ぼかしガラス（glassmorphism）の多用**
- 出典: S3、S6（取得日 2026-10-01）
- 特徴: ナビバー、カード、モーダル、サイドバーに同時に backdrop-filter: blur をかけ、すべてが同じすりガラスの層に乗っている。
- なぜ既定の形か: S3 によると、全面がガラスになると前景がなくなり、階層が平らになる。上限は1〜2要素。S6 は、特定の効果のためではない装飾としてのガラスとぼかしを既定の癖としている。
- teate1122で見る点: 夜のヒーローの上に、すりガラスのナビやカードを重ねていないか。

**A4. 発光（glow）と、ずれのない色付きの光輪**
- 出典: S3、S6（取得日 2026-10-01）
- 特徴: カード、ボタン、アイコン、バッジ、背景、枠線に同時に発光をつける。box-shadow のずれが0で、色付きのぼかしだけがある。
- なぜ既定の形か: S3 によると、発光は注意を強める道具で、全部につけると何も強まらない。「AIが作った」と見られる最も早い道の一つだという。S6 によると、ずれが0の色付きの光輪は奥行きではなく装飾である。
- teate1122で見る点: 炎、ボタン、見出しに橙の glow を一律につけていないか。題材が灯りなので特に起きやすい【推測】。

**A5. 生成りの背景＋コントラストの強い明朝体の見出し＋テラコッタ系のアクセント**
- 出典: S2（取得日 2026-10-01）
- 特徴: S2 は、いまの AI 生成デザインが集まりやすい型の1番目に「暖かいクリーム色の背景（#F4F1EA 付近）、コントラストの強いセリフの見出し、テラコッタか粘土色のアクセント（#D97757 付近）」を挙げている。
- なぜ既定の形か: 題材に関係なく現れる既定の型だから。ただし S2 は、ブリーフが方向をはっきり決めている場合はブリーフに従う（ブリーフの言葉が常に優先）とも書いている。
- teate1122で見る点: **最重要の確認項目。** 「生成り＋灯りの橙」はブリーフの指定なので、使うこと自体は問題ない。問題は、生成りが #F4F1EA 付近、橙が #D97757 付近、見出しが高コントラストの明朝、という既定の型そのままになっていないかである。ブリーフにある**苔色**と**縦組み**がこの型との違いを作るはずなので、それが実際に効いているかを見る。

**A6. ほぼ黒の背景に、鮮やかなアクセント1色**
- 出典: S2（取得日 2026-10-01）
- 特徴: ほぼ黒の背景に、蛍光の黄緑や朱色を1色だけ置く。#0B0B0B や #111 のような色味のある近黒を、黒の代わりに使う。
- なぜ既定の形か: S2 が既定の型の2番目と5番目に挙げている。
- teate1122で見る点: 夜のヒーローとフッターが「#111 付近＋橙1色」の型になっていないか。夜の色は、キャンドルを灯す時間帯の光から決めた根拠があるか（R7）。

**A7. 理由のないダークモード、分類で決めた明暗**
- 出典: S3、S6（取得日 2026-10-01）
- 特徴: 「それらしく見える」という理由だけで、ページ全体を暗くする。
- なぜ既定の形か: S3 は、暗さは決定であって既定ではないとしている。S6 は、分類で明暗を選ぶことを既定の癖とし、誰が、どこで、どんな周囲の光で使うかから選ぶよう求めている。
- teate1122で見る点: 夜の配色の理由が「高級感」などの一般論になっていないか。

**A8. 全要素に同じ角丸、同じ柔らかい影**
- 出典: S2、S3（取得日 2026-10-01）
- 特徴: 階層に関係なく、すべてに同じ border-radius をつける。すべての下に同じ灰色の柔らかい影（S2 の例は rgba(0,0,0,.1)）がある。ボタン、入力欄、カード、バッジがすべて丸い。
- なぜ既定の形か: S2 の「SaaS カードキット」の型。S3 によると、全部が浮くと浮くことに意味がなくなり、角丸は階層の道具ではなく装飾になる。

### 1-B. レイアウト・構成

**A9. 中央寄せのヒーロー＋小見出し＋CTA2つ、その後に定型セクションが続く**
- 出典: S3（取得日 2026-10-01）
- 特徴: ヒーロー、サブタイトル、CTA2つ、画面写真、機能グリッド、推薦文、FAQ、CTA、フッターが毎回同じ順に並ぶ。どのセクションも「中央寄せの見出し＋小見出し＋同じカードグリッド」になっている。
- なぜ既定の形か: S3 によると、この順は商品の物語ではなく学習データの既定である。セクションは内容が必要とするからではなく、テンプレートにあるから現れる。
- teate1122で見る点: 縦組みのヒーローの下が、横組みの定型 SaaS 構成に戻っていないか。推薦文や FAQ を「あるもの」として置いていないか。

**A10. 同じ形のアイコンカード3枚、カードの入れ子**
- 出典: S2、S3、S5、S6（取得日 2026-10-01）
- 特徴: 「アイコン＋見出し＋短文」のカードが、同じ大きさで3枚（または4枚）並ぶ。カードの中にカードがある。
- なぜ既定の形か: S6 は「同じ大きさのアイコン＋見出し＋本文カードをページの骨組みにすること」を既定とし、入れ子のカードは常に誤りとしている。S3 によると、同じ形のカードでは重い内容と軽い内容が同じに見える。S5 は「カードの中のカード」を代表的な兆候に挙げている。
- teate1122で見る点: 「手作り」「天然素材」「香り」のような3つの特長を、同じ形のカードで並べていないか。

**A11. 「使い方は3ステップ」、3項目へのこだわり**
- 出典: S3、S4、S7a（取得日 2026-10-01）
- 特徴: 丸いアイコン＋番号1・2・3＋短文、という手順の表示。コピーでも何でも3つに揃える。
- なぜ既定の形か: S3 によると、実際の手順がきれいな3段階であることは少ない。S4 と S7a は「3つ並べたがる」こと自体を兆候としている。

**A12. 不要な連番（01 / 02 / 03）**
- 出典: S2、S6（取得日 2026-10-01）
- 特徴: 順序のない各セクションの見出しに 01、02、03 を振る。
- なぜ既定の形か: S2 によると、番号は内容が本当に順序（手順や時系列）のときだけ使う。S6 も、順序そのものが読み手に必要な情報でない限り避けるとしている。

**A13. 4列の定型フッター**
- 出典: S3（取得日 2026-10-01）
- 特徴: 製品／会社／リソース／法的情報、の4列が毎回同じ形で並ぶ。
- なぜ既定の形か: S3 によると、列はリンクの群がそれだけあるからではなく、テンプレートにあるから存在する。
- teate1122で見る点: 夜のフッターが、中身の少ない4列になっていないか。

### 1-C. 文字組・装飾

**A14. 見出しの上の小さな英字ラベル（アイブロウ）、字間を広げた大文字**
- 出典: S2、S3、S6（取得日 2026-10-01）
- 特徴: 各見出しの上に「ABOUT」「CONCEPT」「OUR STORY」のような、字間を広げた小さな大文字のラベルがある。H1 の上に、点つきの枠で囲んだ小さなバッジがある。
- なぜ既定の形か: S2 は「大文字のラベル」と「内容の上の不要なラベル」を、生成ページの最もよくある兆候に挙げている。S6 は見出し上のキッカー（アイブロウ）を、ブリーフがあっても取り戻せない禁止事項としている。S3 によると、見出しと同じことを繰り返すラベルは事実を増やさない。
- teate1122で見る点: 日本語見出しの上に英字ラベルを添える型は、日本のブランドサイトでもよく見る。英字が情報を増やしているか、見出しの重複かを確かめる【推測：日本のサイトで多いという点は未検証】。

**A15. 見出しの中で一語だけ色・斜体・太字にする**
- 出典: S2（取得日 2026-10-01）
- 特徴: 「灯りのある**暮らし**」のように、一語だけアクセント色や斜体にする。
- なぜ既定の形か: S2 が、最もよくある文字組の兆候の1番目に挙げている。

**A16. 中黒でつないだメタ情報、リンクの「→」、間を空けた全角ダッシュ**
- 出典: S2、S3、S7a（取得日 2026-10-01）
- 特徴: 「A · B · C」の形のメタ情報。すべてのリンクやボタンの末尾に「→」がある。「WORD — 断片」の形のラベル。本文中の全角ダッシュ（——）。
- なぜ既定の形か: S2 は題材と関係なく出るテンプレートの飾りとしている。S3 は全ボタンの矢印を、何も指さない模様としている。S7a は全角ダッシュと中黒での3項目並列を記号の兆候としている。

**A17. 絵文字や汎用アイコン（キラキラ、星、稲妻）、一つの線画アイコンライブラリの見た目**
- 出典: S3、S6（取得日 2026-10-01）
- 特徴: 見出しや箇条書きに ✨ や 🌿 がある。どこにでもある細い線の角丸アイコン（S3 は Lucide を例示）が並ぶ。
- なぜ既定の形か: S3 によると、絵文字は「書かれたのではなく生成された」ことの最も目立つ合図で、既定のアイコンライブラリはどのサイトでも同じ見た目になる。S6 は、絵文字や Unicode 記号をアイコンの代わりに使うことを既定としている。

**A18. どの案件でも同じ既定のフォント**
- 出典: S1、S3、S5（取得日 2026-10-01）
- 特徴: 欧文では Inter、Roboto、Arial、システムフォント、Space Grotesk。
- なぜ既定の形か: S1 は使い古されたフォントとして明示し、別の候補を禁じても Space Grotesk のような別の定番に集まると書いている。
- teate1122で見る点: 和文で Noto Sans JP、Noto Serif JP、游明朝などを「とりあえず」選んでいないか【推測：和文フォントの既定については出典なし】。書体の選択に、題材や縦組みに合う理由が書けるかを見る。

### 1-D. 動き

**A19. 全セクションのフェードアップ、全カードのホバー効果、終わらない脈動**
- 出典: S2、S3、S6（取得日 2026-10-01）
- 特徴: スクロールすると、どのセクションも下から浮き上がって現れる。全カードにホバーで浮く効果がある。光る点や要素が、操作がなくてもずっと脈打っている。
- なぜ既定の形か: S2 によると、各セクションのフェードアップと全カードのホバー遷移は汎用の既定で、AI 生成に見える。S3 によると、終わらない動きはノイズで、利用者を休ませない。
- teate1122で見る点: 炎のゆらぎを、ページのあちこちで無限ループさせていないか。

### 1-E. 内容の正直さ

**A20. 根拠のない数値、架空の推薦文、実在しないロゴの列**
- 出典: S3、S4（取得日 2026-10-01）
- 特徴: 「10,000人以上が愛用」「満足度98%」のような数値。実在しない人名と肩書きの推薦文。ヒーロー直下に並ぶロゴや掲載実績。
- なぜ既定の形か: S4 によると、具体的に見える捏造は、あいまいな主張より悪い。正直に見えて偽だからである。S3 によると、検証できるロゴのないロゴの列は、証拠のない信頼の主張である。
- teate1122で見る点: お客様の声、販売数、「〇〇万個」「〇〇年の経験」が実データか。実データがなければ、項目ごと削る。

### 1-F. コピー（英語圏の指摘）

**A21. 内容のない派手な語彙（seamless、elevate、unlock、journey など）と意義の水増し**
- 出典: S4、S8（取得日 2026-10-01）
- 特徴: S4 は unlock、elevate、empower、delve、showcase、testament、landscape、journey、robust、game-changer、next-level、seamless、cutting-edge、revolutionary を挙げ、「the future of X」「a new era of」のような意義の水増しも挙げている。
- なぜ既定の形か: S4 によると、これらは人間の文章よりも機械が書いた文章で目立って多く現れ、伝えるためではなく感心させるための語である。
- 日本語での対応: 「シームレスな」「体験をもっと〜に」「新しい〜のかたち」「〜の新常識」は、これらの直訳か同じ型と考える【推測：日本語での対応づけは出典なし】。

**A22. 対比と否定の型（「AではなくB」「Aでもない、Bでもない、Cだ」）**
- 出典: S4、S7c、S8（取得日 2026-10-01）
- 特徴: 「ただのキャンドルではなく、時間をつくるもの」「飾るためでも、香りのためでもない。」のような文。
- なぜ既定の形か: S7c によると、平らな内容に構文で起伏をつける癖で、英語圏の「予告された反転」の型を持ち込んだものである。直してBを直接書くよう求めている。S8 も同じ型を一覧にしている。

### 1-G. 日本語コピー

**A23. 短文と体言止めを重ねる「劇的な断片化」、短文の対句**
- 出典: S7c、S7d（取得日 2026-10-01）
- 特徴: S7c の例は「シンプル。それだけ。それが本質。」「速く。正確に。継続的に。」。S7d の例10は「速く。深く。そして静かに。それが、これからのスタンダードになる。」。
- なぜ既定の形か: S7c によると、短文の連発で深さを演じ、体言止めと句点で「間」を作ろうとする癖である。
- teate1122で見る点: 「灯す。ほどける。ととのう。」のような三連の短文、「静かな夜に、やわらかな灯りを。」型の対句がヒーローにないか。対句については出典は体言止めの断片化までなので、対句一般を AI の兆候とみなすのは【推測】。

**A24. 主体のない比喩的な動詞（false agency）と、体験の大げさな一般化**
- 出典: S7c、S7d、S8（取得日 2026-10-01）
- 特徴: 人ではない物が人の動詞を取る。S7d の例11は、大浴場の体験を「忙しなさが、嘘のように溶けていく」「現代社会で失われつつある『余白』」と書く AI 版で、「溶けていく」を false agency、「余白」「現代社会」を壮大化として直している。

**A25. AI が好む抽象語・質感語、強い漢語の多用**

## 3. 監査での使い方（短い手順）

1. 各画面、各文について「別のキャンドル、香り、雑貨ブランドに差し替えても成立するか」を問う（定義と R4）。
2. A1〜A25 は、一つ当てはまっただけで不合格にしない。S4 は、単独の兆候ではなく**かたまり**を見るよう述べている（「全角ダッシュ1つでは何も意味しない。全角ダッシュ＋3項目並列＋決まり文句＋汎用的な結論が揃うと告白になる」）。
3. ブリーフの指定（生成り、苔色、灯りの橙、縦組み、夜のヒーローとフッター）は、既定の型と重なっても違反にしない（S2）。見るのは、指定を**どう実装したか**が既定の型に寄っていないかである（特に A5 と A6）。
4. 指摘には、該当する項目番号と出典 ID を付ける。【推測】の項目に当たる指摘は「推測に基づく」と明記する。

## 4. この基準を監査に使うときの注意

- **流行は変わる。** S1 は、指示で一つの既定を避けさせると別の定番（例：Space Grotesk）に集まると報告している。S2 の型の一覧も「いま集まっている型」と書いている。この文書の項目は 2026-10-01 時点の観察なので、監査のたびに新しい調査結果で更新する。特に A5（生成り＋テラコッタ系）のような型は、生成モデルの変化で変わりやすい。
- **出典の性質。** 出典の多くは、AI エージェント向けのガイダンスやコミュニティのリポジトリで、書き手の観察である。統計的に検証された「AI らしさ」の指標ではない。
- **実在サイトの調査が欠けている。** 通信制限のため、受賞サイトや同業のブランドサイトを開けていない。参考の項目は原則だけである。制限を外して実在の事例を確認し、2章に原則として追加する（配色、レイアウト、文言は写さない）。
- **【推測】の項目は弱い根拠である。** 特に日本語コピーの「寄り添う」「ひとつひとつ」「丁寧に」「〜を、もっと〜に」は出典がない。修正を要求するより、確認を促す扱いにする。
- **削るだけでは終わらない。** slop を取り除くと無菌的な既定（R5）が残る。削ったあとに、題材に根ざした方向（R1〜R3）を足す。
